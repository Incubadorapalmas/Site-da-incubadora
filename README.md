# Site da Incubadora de Palmas IFPR/PMP

Este é o site da Incubadora de Empresas de Palmas, vinculada ao Instituto Federal do Paraná - Campus Palmas.

## Como executar

1. Certifique-se de que o PHP está instalado no seu sistema.
2. Abra o terminal na pasta do projeto (`d:\IncubadoraIFPR`).
3. Execute o comando: `.\php-8.5.6-nts-Win32-vs17-x64\php.exe -S localhost:8000`
4. Abra o navegador e acesse `http://localhost:8000`

## Funcionalidades

- Página inicial com informações sobre a incubadora.
- Seções: Sobre, Serviços e Contato.
- Navegação suave entre seções.
- Formulário de contato que salva mensagens em um arquivo `contatos.txt`.
- Estilos responsivos e validação simples com JavaScript.

## Troubleshooting

- Se o PHP não estiver instalado, baixe e instale do site oficial: https://www.php.net/downloads
- Certifique-se de que a porta 8000 não está em uso.
